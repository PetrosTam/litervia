## Routes / contract

- `GET /`: privately non-cacheable Blade page with `data-hero-image` for React; selection from 02/06/07, excluding the cookie's last ID if valid. Cookie `lv_previous_hero` is HttpOnly, SameSite=Lax, secure under HTTPS, 7 days, no personal data.
- `GET /research`: existing view route and same SEO placeholder, no selection/cookie side effect.
- `GET /api/home/hero-images`: returns `{ "data": [ {"id", "title", "desktopSrc", "mobileSrc"},... ] }`, static allowlisted descriptors. **HTTP `Cache-Control: private, no-store`** because the Laravel `web` middleware may issue a session cookie. The normal-middleware regression test checks both directives without assuming header order and confirms that the manifest does not set the previous-hero cookie. The manifest remains publicly accessible, but must not be shared-cached. No uploaded path or private user data is exposed.
- Client-side Research-to-Home navigation without a document reload falls back to a stable 06 image. This is an explicitly documented limitation; a future navigation-aware selection without extra first-load latency needs separate review.
